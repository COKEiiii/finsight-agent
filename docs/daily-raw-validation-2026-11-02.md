# 按日批量原始行情：可选增量路径

记录日期：2026-11-02。新路径使用 `--price-source daily` 显式启用，默认 `auto` 和每日任务仍走原路径。策略保持 `strategy_v0.1`。

```bash
finsight sync --provider akshare --universe mainboard --limit 100 --price-source daily --financial-source single --background
finsight jobs show JOB_ID
finsight sync --provider akshare --resume JOB_ID
```

先保持财务来源一致，单独核对价格路径。年报分页是独立选项，不能把财报数值或精度差异算作价格路径的效果。任务保存价格来源，恢复时不能更换；旧任务缺少此字段时按 `auto` 读取。

## 增量更新怎样减少请求

有本地行情底座时，程序根据原有的最近十个交易日重取窗口及遗漏日期，按日期请求 BaoStock 全市场原始日线，再为各股票截取自己的区间。每个日期单独保存请求检查点和原始 Parquet。批量范围最多覆盖最近 61 个交易日；没有底座、历史窗口过旧或需要更长历史时，继续逐股获取历史。

后复权价格仍调用原有逐股 `adjustflag=1` 接口，不根据缺失事件推断因子 1，也不按锚点自行外推。完整日期和股票记录均具备时，可省去该股票原有的 `adjustflag=3` 请求；估值直接采用同一原始响应中的 `peTTM`、`pbMRQ`。批量接口耗时与股票数量不成比例，小验证批次可能更慢，必须分别衡量冷启动、缓存复用和完整主板更新，不能预先宣称总采集提速幅度。

## 数据与恢复约束

- 工作进程在写入成功缓存前核验日期、不复权标记、必需字段、证券代码格式及重复项；不截取或隐藏错误日期。
- 当前任务恢复复用已成功日期的原始观测；新的跨日任务重新检查最近窗口。同日其他批次可以共享整个市场的原始响应，股票池成员、快照及排名仍分别绑定自己的清单。
- 任一日期失败即停止该轮批量预取；部分窗口、缺少股票或超出预取范围时，使用逐股原始行情回退，并保留缺失成员数、失败日期和原因。
- “日期已完成”与“成员齐全”分别记录。`partial_members` 代表批量成员有缺口，不等同于正常规则排除；最终质量仍由实际可用字段、覆盖率和日期统一判定。
- 停牌或未知状态、空成交量和空成交额保留原值。PE-TTM 不替换成动态 PE。
- 行情记录保存原始与复权响应两者较晚的首次观测；估值保存所属日期批量响应的首次观测。原始缓存的读取不改写首次抓取时间。来源标识明确区分两种接口。
- 缓存的逐股原始或复权序列缺少目标交易日时，只额外强制重取一次；新响应仍缺失则保留质量缺口，不进行请求循环。
- 批量请求沿用 120 秒预算，逐股请求仍为 30 秒；并发、速率和重试上限不扩大。来源断路及连接保护继续生效。

CLI 的任务状态新增 `daily_raw_status`、`daily_raw_dates_completed/total`、`daily_raw_missing_members` 和失败日期。界面仍可查看这些任务和最终质量；本阶段没有切换界面默认采集配置。

## 已验证范围

合成完整流程对照包含初始化、增量更新、财务、选股、快照保存和导出。两条路径的所有因子、得分、排序和排除项一致；市场及估值来源标识分别保留，因子输入内容标识一致。断点、跨日重取、未知状态、缺失成员、超出窗口、陈旧底座、缓存缺少当日行情和恢复配置绑定均有测试。
